# JC Java redesign

Preserve the existing logo, purple/yellow identity, branded cup, and serif headlines. Improve hierarchy and booking clarity without replacing the brand.

## Design system
- Java purple #4D1B59; deep purple #32113B; sunshine #F4D339; white #FFFFFF; pale lavender #F5F0F7; text #302735.
- Georgia display headlines paired with a system sans-serif for readable navigation, packages, and forms.
- Left-aligned hero copy with the original branded cup on the right. Quiet white content sections and one purple purpose section.
- Mobile stacks content in reading order and provides an accessible menu.

```text
Logo | Our story  Packages  Our purpose | Call / Plan your event
Slogan + event-service explanation    | Original branded cup
Coffee service introduction           | Original brand photograph
Comparable event packages
Bulldog Brew community purpose
Event planner + direct phone/contact routes
FAQ + footer
```

## Process
1. Audit the existing site and retain its recognizable visual assets.
2. Lead with the supplied slogan and explain mobile event service.
3. Make published package options comparable, with clear starting prices.
4. Bring the existing Bulldog Brew purpose story onto the homepage.
5. Provide an event planner that prepares an inquiry, plus working phone and existing contact links.
6. Check mobile layouts, keyboard operation, links, assets, and planner behavior.
7. Before publishing, confirm prices, donation terms, and service details with the owner; connect a direct inquiry backend if desired.
